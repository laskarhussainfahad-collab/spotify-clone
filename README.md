# 🎵 Spotify Clone : Backend Development

A backend development project focused on building a music streaming platform inspired by Spotify using **Node.js, Express.js, and MongoDB**.

This project explores the fundamentals of backend development while implementing real-world concepts such as REST APIs, authentication, database management, middleware, and cloud storage.

## 🚀 Features

* **Server & API Architecture**
  Built a structured backend using Node.js and Express.js with a modular application architecture.

* **Database Management**
  Integrated MongoDB with Mongoose for database connectivity, schema design, and data persistence.

* **RESTful APIs**
  Developed APIs for user registration, authentication, and music management.

* **Authentication & Security**
  Implemented user authentication using **JWT**, cookies, and secure session handling.

* **Input Validation**
  Added validation for user data and API requests to maintain data integrity.

* **Cloud Media Storage**
  Integrated **ImageKit** for efficient storage and management of media files.

* **Middleware**
  Implemented middleware for authentication, CORS, JSON parsing, and protected routes.

* **API Testing**
  Used **Postman** to test and validate backend APIs.
